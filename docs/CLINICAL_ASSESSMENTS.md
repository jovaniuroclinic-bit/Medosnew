# Centro de Autoevaluación Urológica

Las herramientas son tamizajes orientativos. No sustituyen una valoración médica, no diagnostican,
no prescriben tratamientos y no crean un expediente clínico. Las banderas rojas interrumpen el flujo
y remiten a urgencias sin depender de WhatsApp.

IPSS conserva siete reactivos sintomáticos con puntuación de 0 a 35 y una pregunta de calidad de vida
separada. Las evaluaciones de función eréctil e incontinencia usan redacción educativa original porque
el repositorio no contiene autorización verificable para reproducir SHIM/IIEF-5 o ICIQ-UI SF.

La evaluación funcional masculina es una herramienta educativa propia y presenta un perfil de factores,
no una escala diagnóstica validada.

## Privacidad

Todo el cálculo ocurre en el navegador. No se usa almacenamiento, base de datos ni transmisión de
respuestas. WhatsApp recibe solo el nombre de la evaluación, la categoría general y una solicitud de
valoración.

## Instrumentos pendientes

- SHIM/IIEF-5: pendiente de autorización verificable.
- ICIQ-UI SF: requiere solicitud y autorización específica del ICIQ Project.

Las referencias verificadas se mantienen en `src/data/evidence.ts`. Citar una guía no implica aval
formal de la organización correspondiente.
