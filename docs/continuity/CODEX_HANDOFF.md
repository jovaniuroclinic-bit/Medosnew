# Codex handoff

La interfaz operativa principal de terminal es:
`./scripts/centinela`

Antes de modificar la CLI:
1. Ejecuta `./scripts/centinela status`.
2. Ejecuta `./scripts/centinela doctor --check`.
3. Revisa el Policy Engine.
4. No dupliques lógica del Launcher.
5. No agregues secretos ni conexiones automáticas.

Pendiente humano: bóveda, clics y Termux real.
